# Harrison Talent

Recruitment software for Harrison McMillan, with an employer portal, recruiter portal, candidate intake, review and shortlisting.

Production website: https://harrison-talent.vercel.app

## Repository restoration status

This repository was created after the application had already been deployed to Vercel. The recovered Vercel configuration and favicon are present, but the application source files have **not yet been fully restored**.

Missing source files from the existing production deployment:
- `index.html`
- `employer.js`
- `recruiter.html`
- `recruiter.js`

The original deployed files could be identified, but the connected Vercel retrieval returned truncated content. Please do not deploy this incomplete repository over the working production deployment.

The app uses backend functions hosted separately in Supabase. Configuration and credentials should be managed securely and never commit service-role keys or private passwords.
